# 📝 To-Do List App using Python & Tkinter

This is a simple **To-Do List desktop application** built using Python and Tkinter. It allows users to add, mark as complete, and delete tasks. Tasks are saved locally in a JSON file for persistence across sessions.

---

## 🚀 Features

- ➕ Add tasks
- ✅ Mark tasks as completed
- ❌ Delete tasks
- 💾 Automatically saves tasks to a file (`tasks.json`)
- 🖥️ Clean and responsive Tkinter-based GUI

---

## 🛠️ Tech Stack

- **Language:** Python 3
- **Library:** Tkinter (Standard GUI Library in Python)
- **Data Storage:** JSON file (tasks.json)
